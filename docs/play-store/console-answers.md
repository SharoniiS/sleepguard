# תשובות לטפסי הקונסולה — SleepGuard

טיוטת תשובות לעמוד "תוכן האפליקציה" ב־Google Play Console, לפי מה שהאפליקציה עושה בפועל
בגרסה לחנות.

שני דברים לפני שמתחילים:
- לא היתה לי גישה לטפסים החיים, ושמות השדות בקונסולה עשויים להיות קצת שונים. כל מקום שכתוב
  בו "לבדוק בטופס" הוא מקום שבו כדאי לקרוא את השאלה עצמה לפני שעונים.
- התשובות נכונות כל עוד האפליקציה לא שולחת מידע מהמכשיר. אם בעתיד יתווסף ייצוא, גיבוי או כל
  חיבור לאינטרנט, צריך לעדכן את "בטיחות הנתונים" ואת מדיניות הפרטיות.

## גישה לאפליקציה

לבחור: חלק מהפונקציות מוגבלות, ולצרף הוראות. אין התחברות, אבל בלי ההרשאה לנתוני שימוש
האפליקציה ריקה, ובלי הוראות הסוקרים עלולים לראות מסך ריק ולדחות.

ההוראות באנגלית, כי הסוקרים לא בהכרח קוראים עברית. להעתיק כמו שהוא:

```
No account or login is needed.

On first launch the app asks for Usage Access (a special Android permission that cannot be
granted from a runtime dialog):
1. Tap the blue button on the first screen.
2. Android opens Settings > Usage access. Select "SleepGuard" and turn access on.
3. Press Back to return to the app.

The Home tab then shows the last 24 hours of screen activity immediately. A full night report
(Last Night / History tabs) appears once the device has been used across a night, because the
app only reads screen on/off and lock/unlock timestamps that Android has already recorded.

The interface is in Hebrew. All data stays on the device: the app has no INTERNET permission,
no account and no server.
```

## דירוג תוכן

השאלון של IARC. הקטגוריה היא כנראה "כל סוגי האפליקציות האחרים", כי זו לא אפליקציית משחק או
רשת חברתית. לבדוק בטופס.

- **אלימות, תוכן מיני, שפה גסה, הימורים:** לא.
- **אזכורים של אלכוהול או סמים:** כן. שאלון הבוקר שואל אם היה שימוש באלכוהול או בקנאביס.
  האפליקציה לא מעודדת שימוש, היא רק רושמת. הדירוג עשוי לעלות בגלל זה, וזה בסדר, כי קהל
  היעד הוא בני 18 ומעלה. לבדוק בטופס את הניסוח המדויק.
- **אינטראקציה בין משתמשים או שיתוף תוכן:** לא.
- **שיתוף מיקום:** לא.
- **רכישות דיגיטליות:** לא.

## בטיחות נתונים

התשובה המרכזית: האפליקציה **לא אוספת ולא משתפת** אף סוג של מידע.

למה זה נכון:
- לפי ההגדרה של גוגל, "איסוף" פירושו שהמידע יוצא מהמכשיר. עיבוד ושמירה בתוך המכשיר בלבד
  אינם איסוף.
- לאפליקציה אין הרשאת גישה לאינטרנט, ולכן אין לה אפשרות טכנית לשלוח מידע.
- בגרסה לחנות אין ייצוא גיבוי. הוא היה קיים רק במסך הבדיקות, שמכובה בגרסה הזו.

כשעונים "לא" על האיסוף, השאלות על הצפנה ומחיקה בדרך כלל לא מופיעות. אם הן כן מופיעות:
אין מידע שעובר ברשת, ומחיקה נעשית בהסרת האפליקציה או בניקוי האחסון שלה. לבדוק בטופס.

## הצהרת אפליקציות בריאות

חובה לכל אפליקציה. לסמן את התכונות שהאפליקציה באמת מציעה. השמות בטופס עשויים להיות שונים,
לכן לבחור את מה שהכי קרוב:
- מעקב או ניהול שינה.
- בריאות נפשית והתנהגותית.
- מעקב אחרי תרופות.

אם הטופס שואל אם האפליקציה היא מכשיר רפואי: לא. היא לא מאבחנת, לא מטפלת ולא מודדת שינה.

## הרשאות רגישות

ההרשאה לנתוני שימוש לא מופיעה ברשימת ההרשאות שדורשות טופס הצהרה, למיטב ידיעתי. אם הקונסולה
בכל זאת שואלת עליה, זה ההסבר באנגלית:

```
SleepGuard's core feature is a factual night timeline built from screen on/off and
lock/unlock timestamps. Android only exposes these through UsageStatsManager, which requires
the user to grant Usage Access. The app reads no app names, content or other usage data, keeps
everything on the device, and has no INTERNET permission.
```
